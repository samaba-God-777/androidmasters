# Procedimientos oficiales versionados

Un archivo JSON por fabricante. Son **instrucciones para el propietario**: AndroidMasters nunca las ejecuta como comandos.

Reglas:
- Solo pasos publicados o documentados por el fabricante o por Google. Sin atajos, menús ocultos ni herramientas de terceros.
- Al cambiar los pasos de un procedimiento, **incremente su `version`**: la revisión del taller queda invalidada y vuelve a pedirse.
- Los nombres de los menús cambian según el modelo, la región y la versión del sistema. Cada procedimiento debe revisarlo un administrador del taller (Configuración › Fabricantes › «Marcar como revisado») antes de usarlo con clientes.
- Enlaces solo `https://` a dominios oficiales.
